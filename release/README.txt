Black Ops Game Saves — Windows installers

1. Run InstallGameSaveMod.exe and select the folder containing BlackOps.exe.
2. Run InstallBlackOpsGameSaves.exe and select the same folder.
   The Desktop shortcut option is selected by default.
3. Open Black Ops Game Saves from the Desktop shortcut or from
   mods\Game Save\BlackOpsGameSaves.exe.

The installers do not contain personal checkpoints. In the save manager,
use Export selected or Export all to make a .bo1gamesave file, copy that
file to another computer, and choose Import saves there.
Hold Shift or Ctrl in a map's save list to select several saves before
using Export selected or Delete selected.

The game executable must match the supported Black Ops build. The mod
installer checks this before copying its files. Existing checkpoints
are retained when installing again.
